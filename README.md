# Лабораторна робота № 3 — чисельні методи для задачі Коші

**Виконавець:** Бойог Сергій Степанович, ІПЗ-4. **Варіант № 1.**

Початкова задача: **y′ = y + eˣ, y(0) = 1, x ∈ [0;1]**. Точний розв’язок: **y = (x + 1)eˣ**.

## Запуск

Програма працює без сторонніх залежностей. Найпростіше відкрити **`index_offline.html`** подвійним натисканням. Для запуску модульної версії:

```bash
cd LR3_ODE_Boioh_Serhii
python3 -m http.server 8000
```

Відкрити `http://localhost:8000/`. Файл `index.html` напряму через `file://` використовує ES-модулі і може блокуватися політиками браузера; для цього є `index_offline.html`.

## Перевірка

Потрібен **Node.js 20 або новіший**.

```bash
npm ci
npm test
npm run analyze
```

Локальна перевірка: **43 тести пройдено**, 0 помилок. Команда `npm run analyze -- --save` зберігає точні результати вимірювань у `docs/analysis.json`. Час виконання залежить від комп’ютера і не є універсальною характеристикою алгоритму.

CI: `.github/workflows/tests.yml` автоматично запускає `npm ci`, `npm test` та `npm run analyze` після **push** або **pull_request**. CI діятиме **після публікації проєкту** у власному GitHub-репозиторії.

## Функціональність

- Метод Ейлера (1-й порядок), метод Хойна (2-й), метод Рунге–Кутта 4-го порядку.
- Патерн **Strategy**: окремі класи у `src/solver.js`, універсальна функція `solveODE(problem,strategy)`. Для розширення створити клас із методом `step(...)` і додати його до реєстру `strategies`.
- **Рівно 6 обов’язкових графіків:** три порівняння точного розв’язку та методів (n=5,10,20), три графіки абсолютної похибки (n=5,10,20). Плюс великий графік активної вибірки.
- Автоматичні межі X та Y за усіма видимими значеннями та адаптивне SVG-відображення.
- Анімація по кроках; якщо обрано РК4, відображаються проміжні `k1…k4`.
- Перемикачі кількості кроків 5,10,20 і методу, власна формула, початкова умова, інтервал, JSON імпорт/експорт, CSV експорт.
- Порівняння похибок, часу, відношень `e(h)/e(h/2)`.
- Окремий дослід стійкості `y′ = −20y`; для Ейлера множник `q = 1−20h`.
- Бонус: система Лотки–Вольтерри (2 рівняння) та фазовий портрет методом РК4.
- Введення математичних виразів обробляється власним парсером без `eval` та `Function`.

## Чисельні спостереження

Для варіанта 1 отримано значення відношень кінцевих похибок:

| Метод | 5→10 | 10→20 | Теоретична межа |
|---|---:|---:|---:|
| Ейлер | 1.8403 | 1.9131 | 2 |
| Хойн | 3.6614 | 3.8275 | 4 |
| РК4 | 14.5908 | 15.2776 | 16 |

Для тесту стійкості Ейлера: `n=5 → y(1)=-243`, `n=10 → y(1)=1`, `n=20 → y(1)=0`. При `n=20` розв’язок **стійкий, але не точний у перших вузлах**: вже після першого кроку Ейлер дає 0, тоді як точний розв’язок додатний.
